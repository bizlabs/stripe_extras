This is an Odoo version 17 module to add on-reader tipping and refunds to the pos_stripe module.

This module uses the reader tipping configuration but you must set the configuration in your stripe.com dashboard.
Future version may allow setting the configuration from Odoo.

This was created and tested for my environment only, using a BBPOS WisePOS E stripe reader on odoo version 17.

Please test fully in your environment before using.  The 'test' branch includes code for the stripe reader simulator.

Feedback and comments are welcome.
